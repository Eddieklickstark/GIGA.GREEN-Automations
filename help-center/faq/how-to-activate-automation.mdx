## Quick Answer

To activate a new automation:

1. Log in at `https://dashboard.giga.green`
2. Go to **Automations** in the sidebar
3. Click **New Automation**
4. Select a template or create custom
5. Set triggers & actions (e.g. "If usage > 50kWh, send alert")
6. Click **Activate**

Your automation will run with each new event that matches the trigger.
