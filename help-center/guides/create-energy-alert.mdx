---
title: Create an Energy Usage Alert
description: Set up an energy usage automation in GIGA.GREEN.
---

## Tutorial

<Steps>
  <Step title="Open Automations">
    Log in and go to **Automations** from the sidebar menu.
  </Step>
  <Step title="Choose Template">
    Select the **Energy Alert** template.
  </Step>
  <Step title="Configure Trigger">
    Set usage threshold, e.g. **If usage > 40kWh**.
  </Step>
  <Step title="Set Action">
    Choose **Send Email** or **Push Notification**.
  </Step>
  <Step title="Save & Activate">
    Click **Save**, then hit **Activate** to start monitoring.
  </Step>
</Steps>
