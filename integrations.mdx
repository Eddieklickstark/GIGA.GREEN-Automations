## Setting Up Webhooks

You can receive instant notifications when energy production changes or contracts update. Follow these steps to configure webhooks.

<Steps>
  <Step title="Create Endpoint" icon="terminal">
    Set up a secure HTTPS endpoint that accepts POST requests.
  </Step>
  <Step title="Register Webhook" icon="settings">
    Add the endpoint in your Vantum dashboard under Integrations.
  </Step>
  <Step title="Verify Signature" icon="shield">
    Validate incoming requests using the provided HMAC signature.
  </Step>
</Steps>

## Webhook Configuration Example

Use the following code to handle incoming events in your application.

````javascript
app.post('/webhook/vantum', (req, res) => {
  const signature = req.headers['x-vantum-signature'];
  if (!verifySignature(req.body, signature)) {
    return res.status(401).send('Invalid signature');
  }
  if (req.body.event === 'energy.production.updated') {
    updateDashboard(req.body.data);
  }
  res.status(200).send('OK');
});
````

## API Access for Custom Workflows

You can build custom automations using the REST API. All endpoints require authentication via API key.

<CodeGroup tabs="cURL,Python,JavaScript">
```bash
curl -X GET https://api.example.com/v1/contracts \
  -H "Authorization: Bearer YOUR_API_KEY"
```
```python
import requests
response = requests.get(
  "https://api.example.com/v1/contracts",
  headers={"Authorization": "Bearer YOUR_API_KEY"}
)
print(response.json())
```
```javascript
const response = await fetch("https://api.example.com/v1/contracts", {
  headers: { Authorization: "Bearer YOUR_API_KEY" }
});
const data = await response.json();
```
</CodeGroup>
